# Discord Tournament Management Bot + Professional Dashboard

أريد إنشاء بوت Discord متكامل لإدارة بطولات الألعاب مع لوحة تحكم (Dashboard) احترافية عبر الويب للتحكم الكامل في البطولات والتسجيلات.

## 1. لوحة التحكم (Dashboard)

### إدارة حالة البطولة

* زر لتفعيل البطولة (Enable Tournament).
* زر لإيقاف البطولة (Disable Tournament).

عند إيقاف البطولة:

* إذا ضغط أي مستخدم على زر التسجيل، تظهر له رسالة:
  "لا توجد بطولة متاحة حالياً."

عند تفعيل البطولة:

* أستطيع إنشاء بطولة جديدة وتحديد إعداداتها.
اولا اكتب اسم للبطولة ثم احدد الاعدادت الاتية

---

## 2. أنواع البطولات

عند إنشاء بطولة يجب اختيار أحد الأنواع التالية:

### Solo

### Duo

### Squad

---

## 3. الأسئلة الافتراضية لكل نوع

### Solo Tournament

الأسئلة الافتراضية:

1. اسم الحساب

   * حقل نصي.

2. ID اللعبة

   * أرقام فقط.
   * يمنع إدخال الحروف أو الرموز.

3. الجهاز

   * قائمة اختيار (Select Menu):

     * Mobile
     * PC
     * iPad
     * Controller

---

### Duo Tournament

الأسئلة الافتراضية:

1. اسم حساب اللاعب الأول
2. اسم حساب اللاعب الثاني
3. ID اللاعب الأول
4. ID اللاعب الثاني
5. جهاز اللاعب الأول
6. جهاز اللاعب الثاني
7. اسم الفريق

بالنسبة للـ IDs:

* أرقام فقط.

بالنسبة للأجهزة:

* Mobile
* PC
* iPad
* Controller

---

### Squad Tournament

الأسئلة الافتراضية:

1. اسم اللاعب الأول

2. اسم اللاعب الثاني

3. اسم اللاعب الثالث

4. اسم اللاعب الرابع

5. ID اللاعب الأول

6. ID اللاعب الثاني

7. ID اللاعب الثالث

8. ID اللاعب الرابع

9. جهاز اللاعب الأول

10. جهاز اللاعب الثاني

11. جهاز اللاعب الثالث

12. جهاز اللاعب الرابع

13. اسم الفريق

بالنسبة للـ IDs:

* أرقام فقط.

بالنسبة للأجهزة:

* Mobile
* PC
* iPad
* Controller

---

## 4. نظام تعديل الأسئلة

قبل تفعيل البطولة أريد إمكانية:

* إضافة سؤال جديد.
* حذف أي سؤال.
* تعديل نص أي سؤال.
* تغيير نوع السؤال.

أنواع الأسئلة:

* Text Input
* Number Input
* Select Menu
* Multi Select
* Radio Choice

ويتم حفظ جميع التعديلات قبل تفعيل البطولة.

---

## 5. تحديد عدد المشاركين

عند إنشاء البطولة أريد خيار:

### عدد محدد

مثال:

* 20 لاعب
* 30 لاعب
* 50 لاعب

### أو عدد غير محدود

إذا وصل العدد للحد الأقصى:

* عند ضغط أي مستخدم على زر التسجيل تظهر رسالة:
  "تم اكتمال عدد المشاركين."

---

## 6. أمر إنشاء رسالة التسجيل

Slash Command:

/بطولة

أو

/tournament

عند تنفيذ الأمر داخل أي قناة:

يقوم البوت بإرسال Embed يحتوي على:

* عنوان البطولة.
* وصف البطولة.
* عدد المقاعد المتبقية.
* نوع البطولة.

وزر:

🎮 التسجيل في البطولة

---

## 7. نظام التسجيل

عند الضغط على زر التسجيل:

### إذا كانت البطولة مفعلة

يظهر نموذج (Modal) يحتوي على الأسئلة المحددة للبطولة.

### إذا كانت البطولة غير مفعلة

تظهر رسالة:

"لا توجد بطولة متاحة حالياً."

### إذا كان العدد مكتمل

تظهر رسالة:

"تم اكتمال عدد المشاركين."

---

## 8. إدارة الطلبات داخل الداشبورد

بعد إرسال المستخدم للنموذج:

يظهر الطلب داخل لوحة التحكم.

يتم عرض:

* اسم مستخدم Discord.
* Discord ID.
* تاريخ التسجيل.
* جميع البيانات التي أدخلها.

مع زرين:

✅ قبول

❌ رفض

---

## 9. عند قبول الطلب

عند الضغط على قبول:

* يتم اعتماد التسجيل.
* يتم خصم مقعد من العدد المتبقي.
* يتم إرسال Embed تلقائياً إلى قناة أحددها من الداشبورد.

### مثال للـ Solo

يحتوي الـ Embed على:

* اسم اللاعب
* ID اللعبة
* الجهاز

بشكل مرتب واحترافي.

### مثال للـ Duo

يحتوي على:

* اسم اللاعب الأول

* ID اللاعب الأول

* جهاز اللاعب الأول

* اسم اللاعب الثاني

* ID اللاعب الثاني

* جهاز اللاعب الثاني

* اسم الفريق

بشكل مرتب.

### مثال للـ Squad

يحتوي على:

* أسماء اللاعبين الأربعة
* IDs اللاعبين الأربعة
* أجهزة اللاعبين الأربعة
* اسم الفريق

بشكل مرتب داخل Embed احترافي.

---

## 10. عند رفض الطلب

عند الضغط على رفض:

يظهر Popup أو Modal يحتوي على:

سبب الرفض (اختياري)

وزرين:

* إرسال السبب
* تخطي

### إذا تم إدخال سبب

يرسل البوت رسالة خاصة (DM) للمستخدم:

"تم رفض طلب تسجيلك في بطولة FP.

السبب:
[سبب الرفض]"

### إذا تم اختيار تخطي

يرسل البوت رسالة خاصة:

"تم رفض طلب تسجيلك في بطولة FP."

بدون ذكر أي سبب.
